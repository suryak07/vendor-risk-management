# Third Party Vendor Risk Management System

A web-based cybersecurity application to assess and manage risks associated with third-party vendors.

## Features
- Vendor Risk Scoring (Low / Medium / High)
- Dashboard with Charts
- Secure Login System
- PDF Report Generation

## Technologies Used
- Python (Flask)
- SQLite
- HTML, CSS, Bootstrap
- Chart.js
- ReportLab

## Description
This system helps organizations evaluate vendor security risks and make better decisions before onboarding vendors.
